# PatronPoker — версия 0.2, прототип с аккаунтами

## Запуск

Требуется Node.js 22.13+ (используется встроенный `node:sqlite`).

```bash
npm install
npm start
```

Откройте http://localhost:3100. Для внешнего доступа требуется HTTPS и поддержка WebSocket. `NODE_ENV=production` включает Secure cookie; настройте HTTPS перед включением.

## Что реализовано

- Регистрация, вход, выход, сохранение аккаунтов и сессий в SQLite; пароли хешируются scrypt с индивидуальной солью.
- Приватные комнаты по коду и привязка игрового места к аккаунту; переподключение к живой комнате.
- Серверная колода, приватная выдача карт только владельцу, базовые ставки и шоудаун.
- Bomb Pot с 1–3 бордами и случайным общим анте от minBB до maxBB, отдельное определение победителей каждого борда.
- Настройка BB ползунком 25–500 с шагом 25, стартового стека ползунком.
- PWA-манифест и service worker.

## Известные ограничения — обязательно прочитать

**Это не production-ready приложение и не полноценный корректный покерный движок.** Не реализованы корректные side pots, правила минимального рейза, heads-up позиции, полный порядок действий, корректное возобновление после перезапуска сервера, защита от CSRF во всех сценариях, верификация email, восстановление пароля, масштабирование между процессами, криптографический аудит честности тасования и тесты всех комбинаций. Комнаты хранятся в RAM, при рестарте исчезают. Применяется упрощённая схема выплат, которая может быть неверной при all-in. Для реальных денежных игр использовать нельзя. Нужна отдельная ревизия и тестирование игрового движка и безопасности.

Пользовательские фишки не являются деньгами. В проекте нет платежей.


## Настройки Straddle / Re-straddle (v0.2.1)
Добавлены независимые переключатели и размеры ставок в интерфейс создания стола и серверную конфигурацию. **Механика добровольного объявления Straddle и Re-straddle, их порядок до раздачи и влияние на минимальный рейз пока НЕ реализованы.** Эти переключатели сейчас только сохраняются в конфигурации, и не изменяют раздачу. Не используйте их для настоящей игры до реализации движка.

Бонус 7-2 существует в движке, но требует доработки для побед без шоудауна и проверки side pots.

## v0.2.2 — Straddle / Re-straddle
- Перед обычной раздачей при включённом Straddle игроку после BB предлагается добровольная ставка (размер в BB).
- После принятия и при включённом Re-straddle следующему игроку предлагается повторная ставка с настроенным множителем.
- Предложение можно принять, пропустить; по тайм-ауту пропускается. Bomb Pot исключает эту фазу.
- Ставки проверяются сервером и доступны только игроку, которому сейчас предложено действие.
- Бонус 7–2 начисляется также при победе без вскрытия (если победитель один).

**Ограничения:** это тестовая сборка. Side pots, корректный re-open action при неполном all-in, и полное тестирование порядка ставок ещё не завершены. Не использовать для денежных игр.

## Исправления аудита (v0.2.3)
- Учёт вложений каждого игрока за всю раздачу (`invested`), распределение основного и побочных банков по уровням вложений, в том числе между несколькими бордами.
- Корректная позиция дилера, SB и BB для 2+ игроков; первый ход после BB.
- Победа без вскрытия не публикует закрытые карты в showdown.
- Минимальный размер обычного рейза проверяется сервером. Неполные all-in требуют дополнительных тестов повторного открытия торговли.

`node audit.test.mjs` — семь изолированных проверок. Это не сквозной сетевой тест; релиз для реальных ставок не готов.
